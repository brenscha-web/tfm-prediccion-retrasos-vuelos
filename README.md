# Sistema de Predicción de Retrasos de Vuelos (TFM)Este repositorio contiene la arquitectura completa para la ingesta de datos, entrenamiento del modelo de Machine Learning y despliegue de una API para predecir la probabilidad de retraso en vuelos comerciales.##  Estructura del RepositorioEl proyecto está organizado de la siguiente forma:```tfm-prediccion-retrasos-vuelos/│├── app/                      # Código de la aplicación y API│   ├── flask_app.ipynb       # Notebook de desarrollo de la API│   ├── flask_app.py          # Script ejecutable de la API de Flask│   └── tests                 # Carpeta con tests│         ├── tests.py        # Script cliente para realizar pruebas de peticiones│         └── tests_1.py      # Script cliente para realizar pruebas de peticiones│├── datos/                    # Almacenamiento local de conjuntos de datos│   ├── BTS/                  # Datos históricos de vuelos (Bureau of Transportation Statistics)│   └── NOAA/                 # Datos meteorológicos oficiales (National Centers for Environmental Information)│├── modelo/                   # Modelos entrenados y transformadores serializados│   ├── modelo_retrasos.pkl   # Archivo binario con el modelo predictivo final│   └── encoders_retrasos.pkl # Diccionario de mapeos, target encoders y umbrales│├── notebooks/                # Cuaderno de experimentación y desarrollo│   └── TFM_prediccion_retrasos.ipynb│└── README.md                 # Guía del proyecto (este archivo)```---## Requisitos e InstalaciónPara ejecutar la aplicación localmente, asegúrate de tener instalado **Anaconda** o **Miniconda** y ejecutar los comandos desde tu entorno virtual de Python.1. **Clonar el repositorio** y situarse en la raíz:   ```bash   cd /ruta/a/tu/carpeta/tfm-prediccion-retrasos-vuelos   ```2. **Instalar las dependencias fundamentales**:   ```bash   pip install flask pandas scikit-learn requests   ```---##  Cómo Ejecutar la Aplicación en LocalLa API de predicción está configurada de manera segura mediante rutas absolutas dinámicas y escucha en el puerto **8099** para evitar conflictos de sistema.### 1. Iniciar el Servidor de FlaskAbre una terminal en tu ordenador, muévete a la carpeta `app` y arranca la aplicación:```bashcd apppython flask_app.py```Sabrás que está funcionando correctamente cuando veas la línea:`* Running on http://127.0.0.1:8099`> **Nota importante**: Mantén esta ventana de la terminal abierta mientras > realices predicciones. Para apagar el servidor, presiona `CTRL + C`.### 2. Probar el Modelo (Cliente de Pruebas)Abre **otra ventana de la terminal distinta** y lanza el script de prueba para simular el envío de datos de vuelos:```bashcd tfm-prediccion-retrasos-vuelos/app/testspython test.py```El script enviará un objeto JSON con las características del vuelo (origen, destino, aerolínea, clima, distancia, etc.) y la API responderá de inmediato con la estructura del resultado predictivo:> **Nota**: Puedes usar `tests.py` o `tests_1.py` o generar uno nuevo con la > misma estructura.```json{  "delay_probability": 0.886,  "prediction": "Delayed",  "threshold_used": 0.4}```### 3. Especificación de la API (Esquema del JSON)Para realizar una predicción, se debe enviar una petición `POST` al endpoint `/predict` con un JSON que contenga las siguientes claves:| Campo | Tipo | Descripción / Formato | Ejemplo || :--- | :--- | :--- | :--- || `origen` | *String* | Código IATA del aeropuerto de origen (3 letras) | `"FLL"` || `destino` | *String* | Código IATA del aeropuerto de destino (3 letras) | `"ATL"` || `aerolinea` | *String* | Código de la aerolínea única operadora | `"B6"` || `distancia` | *Integer*| Distancia del vuelo en millas | `581` || `hora` | *Integer*| Hora de salida programada (formato 24h, de 0 a 23) | `18` || `temperatura_c` | *Float*  | Temperatura ambiente en grados Celsius | `29.5` || `punto_rocio_c` | *Float*  | Punto de rocío en grados Celsius | `24.0` || `viento_ms` | *Float*  | Velocidad del viento en metros por segundo | `14.5` || `visibilidad_m` | *Integer*| Visibilidad en metros | `9000` || `precipitacion_mm`| *Float*  | Cantidad de lluvia/precipitación en milímetros | `6.5` || `temporada_alta` | *Integer*| Indicador binario (`1` para temporada alta, `0` si no) | `1` || `indice_congestion`|*Integer*| *[Opcional]* Índice de tráfico aéreo (por defecto `20`) | `25` || `franja_horaria_enc`|*Integer*| Identificador codificado de la franja horaria | `3` || `bin_visibilidad_enc`|*Integer*| Identificador codificado del rango de visibilidad | `2` || `bin_precipitacion_enc`|*Integer*| Identificador codificado del rango de precipitación | `2` |---
